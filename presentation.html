SECTION 01 • INTRODUCTION
THE FOUR CORE DAA PILLARS
01. KNAPSACK DP
O(n · W) • GLOBAL OPTIMUM
• Solves discrete 0/1 order selection within payload limit W.

• 2D memoization table guarantees zero wasted space.

• Backtracking golden trail identifies exact parcel bundle.
02. GREEDY HEURISTICS
O(n log n) • APPROXIMATION
• Priority sorting by Profit Density (Rs./kg), Deadline, and Profit.

• Fast heuristic execution in under 0.5 ms.

• Prone to greedy traps for integer discrete cargo.
03. DIJKSTRA SSSP
O((V+E)logV) • MIN-HEAP
• Custom Binary Min-Heap Priority Queue implementation.

• Greedily finalizes vertex with minimum tentative distance.

• Optimal routing across non-negative urban road networks.
04. BELLMAN-FORD
O(V · E) • DYNAMIC DP
• Relaxes all |E| edges for |V|-1 iterations.

• Models congestion penalties, toll rebates & detours.

• Detects negative-weight loops preventing routing anomalies.

SECTION 03 • LITERATURE REVIEW
THEORETICAL LITERATURE FOUNDATIONS
Key Finding 1: Dynamic Programming Optimality
Bellman (1957) proved that optimal decisions decompose into subproblems. Martello & Toth (1990) established the 2D memoization recurrence for discrete 0/1 knapsacks.
Key Finding 2: Shortest-Path Graph Duality
Dijkstra (1959) established greedy min-heap expansion for non-negative road graphs. Bellman-Ford (1958) generalized shortest paths via DP edge relaxations with cycle detection.

SECTION 04 • METHODOLOGY
DEEP DIVE: KNAPSACK DP VS GREEDY ALGORITHMS
01. 0/1 KNAPSACK (DP)
BELLMAN RECURRENCE • O(n · W)
Mathematical Formulation:
DP[i][w] = DP[i-1][w] (if wi > w)
DP[i][w] = max(DP[i-1][w], DP[i-1][w-wi] + pi)

• Table Dimensions: (N + 1) × (W + 1)
• Cell decision: SKIP (item excluded) vs TAKE (item included).
• Golden Backtracking: Traces optimal parcel combination.
• Guarantees 100% global revenue capture.
02. PROFIT DENSITY GREEDY
DANTZIG RATIO SORT • O(n log n)
Heuristic Formulation:
Calculate ratio ri = pi / wi for each order.
Sort in descending order and greedily insert while weight ≤ W.

Algorithmic Flaw:
Greedy choice property guarantees optimality only when items are divisible. For discrete parcels, fractional voids waste valuable payload space.
03. ALTERNATIVE HEURISTICS
SLA & BASELINE POLICIES
Comparative Heuristic Strategies:

1. Profit Density: max (pi / wi) — 92.4% Optimal.
2. Highest Profit: max pi — 83.9% Optimal.
Biased toward heavy orders, under-utilizing volume.
3. Earliest Deadline First (EDF): min di — 85.7% Optimal.
Prioritizes urgent customer SLAs.
SECTION 04 • METHODOLOGY
DEEP DIVE: DIJKSTRA VS BELLMAN-FORD ROUTING
DIJKSTRA'S SSSP
MIN-HEAP GREEDY • O((V+E)logV)
Algorithmic Mechanics:
• Initialize dist[start] = 0, dist[v] = ∞
• Push (0, start) to custom Min-Heap Priority Queue.
• Invariant: Extract vertex u with minimum tentative distance. It is permanently finalized.
• Edge Relaxation:
dist[v] = min(dist[v], dist[u] + w(u,v))

Limitation: Requires w(u,v) ≥ 0. Cannot handle negative toll credits.
BELLMAN-FORD ALGORITHM
DP EDGE RELAXATION • O(V · E)
Algorithmic Mechanics:
• Relaxes all |E| directed edges for |V| - 1 iterations:
d(k)[v] = min(d(k-1)[v], d(k-1)[u] + w(u,v))

Cycle Detection Invariant:
If edge (u,v) relaxes on iteration |V|, a negative-weight cycle exists.

Benefit: Handles dynamic congestion penalties & toll subsidies without failure.
