SECTION 01 • INTRODUCTION
WHAT IS
SMARTROUTE?
BRIDGING CLASSICAL DATA STRUCTURES WITH REAL-WORLD LOGISTICS OPTIMIZATION ACROSS HYDERABAD'S URBAN CORRIDORS.

In modern e-commerce delivery networks, last-mile logistics accounts for over 53% of overall supply-chain expenditures. SmartRoute models this high-stakes domain through four rigorous DAA paradigms studied in our coursework:

  • Discrete Knapsack Optimization: Maximizing payload revenue under strict vehicle payload boundaries.
  • Heuristic Greedy Scheduling: Evaluating rapid priority approximations versus optimal formulations.
  • Single-Source Shortest Paths: Comparing Dijkstra's Min-Heap graph navigation with Bellman-Ford's dynamic edge relaxation and congestion arbitrage.
SECTION 01 • INTRODUCTION
THE FOUR DAA PILLARS
A SYSTEMATIC COMPARISON OF DP, GREEDY CHOICE, AND SHORTEST PATHS
01. KNAPSACK DP
BELLMAN 2D MEMOIZATION
Guarantees mathematically optimal order selection within payload limit W in O(n · W) pseudo-polynomial time.
02. GREEDY HEURISTICS
LOCAL CHOICE SORTING
Ultra-fast O(n log n) parcel scheduling by Profit Density (₹/kg), Earliest Deadline, and Highest Absolute Value.
03. DIJKSTRA'S SSSP
MIN-HEAP PRIORITY QUEUE
Rapid greedy edge traversal across Hyderabad's road network in O((V + E) log V) for non-negative road distances.
04. BELLMAN-FORD
DP EDGE RELAXATION
Robust path optimization in O(V · E); detects negative penalty cycles, congestion toll rebates, and deadlock loops.
RESEARCH OBJECTIVE
Rather than viewing these algorithms as disjoint theoretical concepts, SmartRoute establishes a direct comparative testbed across 35+ customer locations throughout Hyderabad.
SECTION 02 • PROBLEM STATEMENT
THE DUAL BOTTLENECK IN URBAN LOGISTICS

LAST-MILE COURIERS FACE TWO INTERCONNECTED COMPUTATIONAL BOTTLENECKS THAT CANNOT BE SOLVED BY INTUITION:

1. The Order Selection Bottleneck (Knapsack Dilemma):
With 35+ pending parcel requests and limited vehicle cargo capacity (e.g. 100 kg), testing all 235 (34.3 billion) combinations by brute force is impossible. Naive greedy sorting frequently leaves empty vehicle payload voids, resulting in severe revenue loss.
2. The Network Routing Bottleneck (Spatial Path Dilemma):
Once orders are chosen, dispatchers must find the optimal transit path from the Begumpet Central Hub through dense traffic corridors (HITEC City, Gachibowli, Secunderabad, Woxsen University). Suboptimal delivery sequences cause exponential fuel waste and SLA penalties.
3. The Real-Time Constraint:
The system must execute both selection and routing algorithms in under 50 milliseconds to support dynamic driver dispatch.

SECTION 04 • METHODOLOGY
DEEP DIVE: KNAPSACK DP VS GREEDY ALGORITHMS
01. 0/1 KNAPSACK (DP)
BELLMAN RECURRENCE • O(N · W)
Mathematical Recurrence:
DP[i][w] = DP[i-1][w] (if wi > w)
DP[i][w] = max(DP[i-1][w], DP[i-1][w - wi] + pi)

• Table Dimension: (N + 1) × (W + 1)
• Backtracking extracts chosen orders by checking if DP[i][w] ≠ DP[i-1][w].
• Guarantees 100% global optimal revenue capture.
02. PROFIT DENSITY GREEDY
DANTZIG RATIO SORT • O(N LOG N)
Heuristic Formulation:
Sort orders by ratio ri = pi / wi in descending order.
Iteratively pick order if curr_weight + wi ≤ W.

Why Greedy Fails Discrete 0/1:
Greedy choice property guarantees optimality only when parcels are divisible. For discrete items, packing voids waste capacity.
03. GREEDY HEURISTIC VARIANTS
PRIORITY CRITERIA COMPARISON
Evaluated Alternative Policies:

1. Profit Density: max (pi / wi) — Fastest practical heuristic (0.4 ms).
2. Highest Profit: max pi — Biased toward heavy items; low count.
3. Earliest Deadline: min di — Prioritizes urgent SLAs over total profit.
SECTION 04 • METHODOLOGY
DEEP DIVE: DIJKSTRA VS BELLMAN-FORD ROUTING
DIJKSTRA'S ALGORITHM
MIN-HEAP GREEDY • O((V+E) LOG V)
Algorithmic Mechanics:
• Initialize dist[start] = 0, dist[v] = ∞
• Push (0, start) to custom Min-Heap Priority Queue.
• Invariant: Greedily extract vertex u with minimum tentative distance.
• Relax adjacent edges:
dist[v] = min(dist[v], dist[u] + w(u,v))

Limitation: Requires w(u,v) ≥ 0. Cannot handle negative toll rebates.
BELLMAN-FORD ALGORITHM
DP EDGE RELAXATION • O(V · E)
Algorithmic Mechanics:
• Relaxes all |E| directed edges for |V| - 1 iterations:
d(k)[v] = min(u,v) (d(k-1)[v], d(k-1)[u] + w(u,v))

Cycle Detection Invariant:
If edge (u,v) relaxes on pass |V|, graph contains a negative-weight cycle.

Handles dynamic penalty adjustments and toll rebates without failure.
PRACTICAL LOGISTICS ROLE
HYBRID DUAL GRAPH ENGINE
Operational Synergies in SmartRoute:

• Primary Routing: Dijkstra executes in 4.2 ms across Hyderabad corridors for instant turn-by-turn directions.

• Congestion Audit: Bellman-Ford runs in background (18.7 ms) to detect traffic deadlock loops and model dynamic incentive subsidies.
